This is an independent evaluation component, not a runtime installed in business
repositories. Read the current parent project's design principles, architecture,
harness boundary, and native-runtime reuse documents before changing behavior.
The authoritative product checkout is `../mindie-agent`.

Keep private raw traces separate from publication artifacts. Never upload trial
data, create public issues or PRs from trials, or retry an unknown paid attempt.

Run `uv run pytest` and `uv run ruff check .`. Before submitting a development PR,
review all nine principles and record the reviewed source and principles revisions,
concrete findings/fixes, validation, and unverified boundaries.
