# mindie-bench 0.4.8：六端插件发行元数据自动生成

[English](mindie-bench-0.4.8.en.md)

共享发布流水线为 Codex、Claude Code、Kimi Code、DSH、Antigravity 和
WorkBuddy 自动准备 `mindie-plugin-release.json`。各仓只需维护源码中的
兼容性声明，发行元数据由已核验的包版本、精确提交和该提交的声明生成。
组件仓继续使用自身发行契约。

生成步骤在打包后、校验和及升级验收前执行。缺少元数据时自动生成；已有文件
必须与候选版本、源码和兼容性声明一致，合法文件保留原始字节。声明缺失、
格式过旧或工作区声明偏离测试提交时直接失败，此时尚未创建发布草稿。

仓库映射、声明路径和校验规则直接复用固定版本的已发布旧更新器。六种真实
声明布局的回归实际生成发行资产，并交给旧版本选择器验证；另覆盖错误已有
资产不被覆盖、旧声明失败和源码不一致。共享流程继续执行真实旧客户端升级、
草稿资产下载校验及正式源再次升级，不放宽消费者校验。

本版本独立发布，不更新历史产品通道，也不改变组件依赖或知识启用授权。
