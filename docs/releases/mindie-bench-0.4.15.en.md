# mindie-bench 0.4.15: Universal 7-Host Native Wire Verifier (`host-accept`) & 3-OS Release Usability Gates

[中文](mindie-bench-0.4.15.md)

`mindie-bench v0.4.15` introduces zero-mock end-to-end release usability qualification (Gate Layer 2 & Gate Layer 3) across all 17 MindIE Agent code repositories:

- **Universal 7-Host Native Wire Verifier (`src/mindie_bench/host_acceptance/` · `mindie-bench host-accept`)**: Exercises all 7 native host plugins (`codex`, `cc`, `kimi`, `dsh` Cordis ESM, `agy`, `wb`, `oc` ESM) directly from their real manifests and release archives across Linux, macOS, and Windows across 4 mandatory scenarios: (1) cold launch byte-0 `stdout` cleanliness, concurrent surface startup, 1:1 schema parity, and live `tools/call`; (2) public `install.py` Turn-1 usability under a fail-closed `git` `$PATH` trap; (3) Hook fast-paths, negative zero-SQLite states, and `local-only` secret-redacted `Stop` capture; and (4) `n-1` formal release -> candidate upgrade cutover (preserving `mindie-consent.json` and custom command wrappers while overriding retired/missing engine paths).
- **Candidate Wheelhouse Substitution & Reusable CI Workflows (`assemble_candidate_wheelhouse.py` · `fullstack-smoke.yml` · `verify-host-plugin.yml`)**: Deterministically overlays candidate `.whl` artifacts onto formal sibling wheels + `reme-ai` (enforcing `HAR-ABI` `dependencies == []`), updates `release-policy.json` (`0.1.17` formal baselines including `harness`), and upgrades `upgrade_acceptance.py` (`wheelhouse.update_runtime` + `selftest --mode full`) and `native_upgrade_acceptance.py` (live `mcpServer/tool/call` for `knowledge_query` and `mindie_doctor`).
- **Pre-Tag Single-Repo & 21-Cell Product Qualification (`publish-release.yml` · `publish-product.yml`)**: Gates `publish-release.yml` behind a 3-OS read-only `usability-gate` before draft/tag creation, and splits `publish-product.yml` into `stage-product` -> `qualify-product` (`3 OS × 7 hosts = 21` cells unpacking the exact staged `mindie-wheels-bundle.tar.gz`) -> `publish`.
