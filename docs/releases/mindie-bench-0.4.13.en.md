# mindie-bench 0.4.13: Zero-Git Wheelhouse, Release Pipeline Speedup, and 1:1 Native `remote-dev` Tool-Surface Scoring

[中文](mindie-bench-0.4.13.md)

`mindie-bench v0.4.13` closes the product-publication, release-pipeline latency, and native `remote-dev` tool-surface contract gaps:

- **Zero-Git prebuilt wheelhouse bundle**: `.github/scripts/build_wheels_bundle.py` reads all nine shared components from the release-channel JSON, verifies each formal tag revision, `SHA256SUMS`, streaming wheel SHA-256, and normalized `METADATA` `Name`/`Version`, builds pure-Python `reme-ai[as]` in an isolated temporary checkout with write tokens stripped, and emits a deterministic `mindie-wheels-bundle.tar.gz` (flat sorted members, `mtime=0`, `mode=0644`, `< 3 MiB`).
- **Unified `release-channel.json` and optional `install.py` publication**: `publish-product.yml` validates `channels/<track>.json` for both `milestone` and `patch`, always passes it to `collect_product_benchmarks.py` so `release-channel.json`/`channel_sha256` are recorded, builds the wheelhouse bundle and stages `product/install.py` before `SHA256SUMS` is computed, and attaches the channel file, bundle, and installer to both release kinds.
- **Release pipeline caching and duplicate-rebuild subtraction**: Enables `astral-sh/setup-uv@v6` caching across `publish-release.yml`, `release-benchmark.yml`, and `publish-product.yml`, shares `UV_CACHE_DIR` across stages in `upgrade_acceptance.py` and `native_upgrade_acceptance.py`, replaces the redundant 25–45 minute `verify-public` full rebuild with a `< 30s` `.github/scripts/verify_public_release.py` public CDN + `SHA256SUMS` check, and extends `check_release_dependencies.py` to accept official GitHub Release wheel URL receipts and thin `mindie-harness`-only host plugins.
- **Wheel-provenance inventory probing and 1:1 native `remote-dev` scoring**: `native_upgrade_acceptance.py` supports `allow_wheel_provenance=True` with legacy consumer fallback, requires `mindie_doctor`, and rejects retired `remote_BashOutput` / `remote_KillShell` tools; `mcp_probe.py`, `target_access.py`, and `tool_observations.py` align 1:1 native remote tool names and arguments (including integer `session_id`, `image_path`, `notebook_path`, and strict `Action="status"` confirmation semantics).
