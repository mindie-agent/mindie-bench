# Corpus-first physical NPU tasks

`k3-gdn-idle-dp-state` is an independently proved DP2/HCCL eager model-state
contract. Its source and precise hardware scope are in its `SOURCE.md`.

For G3, `materialize_g3.py --output /owned/new-pair` creates two **candidate**
tasks that repeat this same defect and verifier in independent native sessions.
The seed begins without exact-origin public packages; only its actual captured
experience can supply the later near-exact view. This deliberately measures
repeated-incident reuse, not cross-defect transfer or two new independent tasks.
No proof is inherited. Run the existing `soundness --promote` separately on
each candidate, freeze the model/runtime/corpus and use the ordinary G3 runner.
Unknown capture blocks the dependent evaluation and must not be retried.
